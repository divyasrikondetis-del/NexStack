# 🚀 NexStack — Developer Community & Knowledge Platform

NexStack is a full-stack developer community platform inspired by Stack Overflow. It provides a place for developers to ask questions, share knowledge, connect with other developers, build reputation, and discover opportunities.

## 🌐 Live Project

**Frontend:** https://nex-stack-ele.vercel.app/

**Backend:** https://nexstack-final.onrender.com/

**GitHub:** https://github.com/divyasrikondetis-del/NexStack
